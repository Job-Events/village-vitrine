Console de gestion du site — liens & actualité

Une seule page pour tout piloter sans toucher au code : les liens des boutons des Villages (onglet Événements) et les posts affichés sur la page Actualité (onglet Actualité). Modifiez, puis cliquez Exporter le JSON et collez-le sur votre page technique Odoo. Le site se met à jour tout seul au prochain chargement.

Chaque colonne = une plateforme. Le 1ᵉʳ post de chaque colonne est mis en avant sur le site. Renseignez la date, le texte (un extrait suffit) et le lien du post. Utilisez ▲▼ pour réordonner, ✕ pour retirer, « + Ajouter un post » pour compléter.

Comment brancher cette page au site (Odoo) — à faire une seule fois

1. Créez sur Odoo une page technique qui renvoie ce JSON (type application/json) avec l'en-tête Access-Control-Allow-Origin: *.
2. Dans le site (index.html), renseignez la constante var SITE_CONFIG_URL='…'; avec l'URL de cette page Odoo, et laissez EVT_LINKS_URL / SOCIAL_URL vides.
3. C'est tout : le site lit liens + actualité à chaque chargement. Pour mettre à jour, vous modifiez cette console, exportez, et remplacez le contenu de la page Odoo — aucun redéploiement du site.
Format complet : { "links": { "2026": {…}, "2027": {…} }, "social": { "linkedin": [ {"d":"JJ/MM/AAAA","t":"…","u":"https://…"} ], "facebook": […], "instagram": […] } }
